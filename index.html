// ABOUT

Engineering mobile products end-to-end, not just screens.

I'm a Senior Software Engineer at TO THE NEW, specializing in React Native across Android, iOS, and Progressive Web Apps. My work spans the full lifecycle of a mobile product — architecture decisions, native module bridging, performance tuning, authentication and security, and the release pipelines that ship it all reliably.

I led the migration of legacy applications to React Native's New Architecture (TurboModules & CodeGen), built a reusable component library adopted across multiple projects, and have shipped features for global platforms in sports betting/iGaming and OTT meditation.

Beyond writing code, I own production health — monitoring crash-free sessions with Sentry and Crashlytics, automating dependency security audits, and building Fastlane pipelines that take releases from days down to minutes. I work closely with product, design, backend, and QA teams inside Agile sprints.
